## Sources et licences

### Licences du dépôt

Le code, la note technique et les résultats agrégés (planches de l'atlas, tableaux, fiches intercommunales) sont publiés sous [Licence Ouverte 2.0](https://www.etalab.gouv.fr/licence-ouverte-open-licence/).

Le GeoPackage, les fichiers de connexions et la carte interactive (`index.html`) contiennent des données dérivées des horaires de transport en commun. Quatre des seize réseaux utilisés les publient sous [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/), qui impose le partage à l'identique : ces fichiers sont donc diffusés sous ODbL, y compris pour la part issue des autres réseaux. Le fichier `LICENCE.txt` détaille le périmètre de chaque licence.

### Attribution

Pour les réseaux sous ODbL, la mention est : « Contient des données issues du réseau [nom], publiées sur transport.data.gouv.fr sous licence ODbL. »

Pour les autres données : « Source : IGN, Insee, producteurs des réseaux de transport. Traitement : SMD, 2026. »

### Réutiliser les données dérivées

Toute base de données construite à partir du GeoPackage, des fichiers de connexions ou de `index.html` doit être publiée sous ODbL. Une carte, une image ou un graphique produit à partir de ces fichiers peut être diffusé sous une autre licence, avec la mention de la source et de la licence des données.
